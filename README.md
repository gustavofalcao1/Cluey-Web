# 💬 Cluey-Web

**Cluey-Web** is an advanced chat application designed with seamless AI integration, offering an interactive, intuitive, and multilingual user experience. Built on ReactJS, Next.js, Firebase, and OpenAI, Cluey facilitates smart conversations, intelligent assistance, and effortless user management.

🌐 **[Live Demo](https://cluey-33308.web.app/)**

## ✨ Key Features

### ✅ Implemented
- **Dynamic Chat Interface**: Real-time message exchange with intelligent AI responses.
- **Authentication System**: Secure login, signup, email confirmation, and password recovery.
- **Theme and Localization**: Dark/Light themes and multilingual support (English, Portuguese, Spanish, French).
- **Interactive UI**: Easy-to-use interface with message presets and user-friendly interactions.

### 🚧 Planned Features
- Fully responsive sidebar and navigation
- "New Cluey" chat initiation button
- Real-time message streaming
- Advanced notification system
- Accurate credit accounting system
- Comprehensive administration interface

---

## 🛠️ Technology Stack

- **Frontend**: ReactJS, Next.js, Styled Components
- **Backend**: Firebase, OpenAI API
- **Internationalization**: JSON-based localization
- **Theme Management**: Dynamic theming with context API

## 🚀 Installation & Usage

Clone the repository and install dependencies:

```bash
git clone https://github.com/gustavofalcao1/Cluey-Web.git
cd Cluey-Web
yarn install # or npm install
```

Start the development server:

```bash
yarn start # or npm start
```

Build for production:

```bash
yarn build
```

Deploy the production build:

```bash
yarn prod
```

### 🟢 Read Receipts System
- Real-time user status management (online, offline, busy, away).
